# Клинико-динамическая характеристика рекуррентного депрессивного расстройства в позднем возрасте

## Обзор

Данный репозиторий содержит автореферат диссертации «Клинико-динамическая характеристика рекуррентного депрессивного расстройства в позднем возрасте», защищённой для получения учёной степени **кандидата медицинских наук** по специальности **14.01.06 — психиатрия**.

Автор **Захарченко Денис Валерьевич**

Научный руководитель **Незнанов Николай Григорьевич** — доктор медицинских наук, профессор

Работа выполнена в **ФГБУ «Санкт-Петербургский научно-исследовательский психоневрологический институт им. В.М. Бехтерева»** (2015).

## Программное обеспечение

Разработанная для этого исследования модель данных стала основой для создания специального программного обеспечения — клинического реестра данных.

**→ [Реестр рекуррентной депрессии (RDD)](https://github.com/denzakh/rdd)**

Этот клинический реестр (Next.js / Cloudflare Workers / D1) является работающим приложением, демонстрирующим, как может быть организована работа врача-исследователя.

Он включает в себя возможность отслеживания фаз, расчет ремиссий и оценку результатов, контроль доступа на уровне строк, ведение журнала аудита и экспорт обезличенных данных для статистического анализа.

## Тема исследования

> **Актуальность исследования.** Проблема депрессий пожилых людей с каждым годом приобретает всё большее значение. Это связано как с более высокой, чем у лиц молодого возраста, распространённостью депрессивных расстройств у индивидулятов, находящихся в инволюционном периоде, так и с тенденцией к увеличению доли пожилых в обществе.

В работе проанализированы клинико-динамические характеристики рекуррентного депрессивного расстройства у пациентов позднего возраста, изучены факторы, влияющие на возраст начала заболевания, продолжительность ремиссий и прогрессирование симптомов.
